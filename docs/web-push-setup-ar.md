# إعداد تذكيرات المهام اليومية عبر Web Push

تعمل ميزة التذكير تلقائيًا من الأحد إلى الخميس والسبت، ولا تعمل يوم الجمعة. يفحص الخادم الحسابات النشطة المرتبطة بمهندس في نافذة **09:30–09:34 بتوقيت القاهرة**، ويرسل تذكيرًا فقط إذا لم توجد مهمة لذلك المهندس في تاريخ اليوم. يوجد قيد فريد يمنع إرسال التذكير أكثر من مرة للمستخدم في اليوم نفسه.

## إعداد مفاتيح VAPID

يجب إنشاء زوج مفاتيح مرة واحدة خارج المستودع:

```bash
pnpm exec web-push generate-vapid-keys
```

أضف القيم الناتجة إلى أسرار بيئة التشغيل، ولا تضع المفتاح الخاص في GitHub أو في ملفات الواجهة:

```text
VAPID_PUBLIC_KEY=...
VAPID_PRIVATE_KEY=...
VAPID_SUBJECT=mailto:admin@your-domain.example
```

## تفعيل المستخدم

بعد تسجيل الدخول، يفتح المستخدم التطبيق من الهاتف ويضغط **تفعيل تذكيرات المهام** من أسفل القائمة الجانبية، ثم يوافق على إذن الإشعارات. يُحفظ اشتراك كل جهاز منفصلًا، ويمكن للمستخدم إيقافه من الزر نفسه.

يجب فتح التطبيق عبر HTTPS في بيئة الإنتاج؛ Web Push لا يعمل من نطاق HTTP عادي. بعد تغيير مفاتيح VAPID، يجب إعادة تسجيل الأجهزة من التطبيق.

## قاعدة البيانات

Migration `0066_web_push_reminders.sql` تنشئ جدول اشتراكات الأجهزة وجدول سجل الإرسال اليومي. يجب تطبيقها قبل تشغيل النسخة الجديدة.
